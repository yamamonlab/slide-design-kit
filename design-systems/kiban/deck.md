# デッキの組み方

1枚ずつ決まりを守っても、デッキ全体が「同じ型の繰り返し」や「空いたスライド」になると伝わらない。どのブランドでも、デッキを組む前と組み終えた後にこのページで確かめる。

## 組む前に決めること

- **目的と型。** 最初に `types.md` から型を1つ選ぶ。構成・主役・使うパターンはその型に従う。以下の決まりは分析・報告と解説・勉強会の型を前提にしたもので、進行・司会と登壇LTでは型の欄が優先する。進行・司会は場面の絵が主役なので、絵を省いた版を作らない。
- **図の配分。** 本文スライドの3分の1以上を、仕組みの図（流れ・構成・段階・時間差・式）にする。残りがグラフ・表・タイル・比較。グラフだけを並べない。
- **隣り合う2枚を同じ型にしない。** 「棒グラフ＋右に読み取り」が続いたら、片方を滝グラフ・段階の流れ・タイルに変える。
- **要旨は「結果3つ＋構造3つ＋論点」。** 上の段に結果のカード3枚、下の段にその裏の関係を示す数字3つ、最後に論点の帯。
- **最後の論点は数字で。** 「今後の注目点」は文の列挙にせず、見るべき数字が大きく出るタイル（3×2）にする。
- **章立てを先に。** 章番号と章名を決め、目次・中扉・各スライドの章の表示を同じ文言にする。

## 1枚ごとに確かめること

- **注記は図の中に。** グラフと図には、点線で対象を指す注記を1〜2つ必ず付ける。読み取りを図の外の欄だけに書かない。注記には数字か判断を書く。
- **差は矢印で。** 前期比・計画比が主張なら、比べる2本の間に比較元の高さの破線と強調色の矢印を引き、差の数字を添える。
- **本文領域の7割を使う。** 下3割以上が空いたら、図を大きくする・数字の段を足す・型を変える。文字を大きくして埋めない。
- **強調は2か所まで。** 強調色の棒・ノード・線・枠を合わせて2つまで。
- **試算と発表を書き分ける。**

## 組み終えたら

- [ ] タイトルだけ、メッセージだけを順に読んで、構成と主張が通る
- [ ] 本文スライドの3分の1以上が仕組みの図
- [ ] 同じ型が2枚続いていない
- [ ] すべてのグラフと図に、図の中の注記がある
- [ ] 本文領域の下3割が空いたスライドがない
- [ ] 強調色は各スライド2か所まで
- [ ] 24px 未満の文字がない（SVG の中の文字も含む。配布用の出典を除く）
- [ ] 物の絵は、用意したセットだけを使っている（その場で描いていない）。絵の中に文字がなく、負の幅・高さの図形もない
- [ ] 進行・司会では、本文スライドのほぼすべてに場面の絵がある
- [ ] 型のパターンにない形を作ったら、`patterns.md` の候補に記録した
- [ ] 試算した数字に「当資料の計算」と書いてある
- [ ] 実物（描画した画像・PDF・投影）で文字切れと重なりを確かめた
