# ChatMock

人とAIのやりとりを、アバターと吹き出しで見せる会話のイメージ図。AIツールの使い方や「AIが同僚として話す」様子を説明するときに使う。

- アバターは 56px・`radius-avatar`。人は `surface` に `rule` 3px と線アイコン、AIは `ink` 塗りに「AI」の文字（`on-ink`、900）。顔・体・ロボットは描かない。
- 吹き出しは人が `surface`、AIが `tint`。どちらも `rule` 3px・`radius-node`、文字は `label`（400）。AIの発言の頭に役割名を書く（「アイデア担当：」）。
- 発言は作り物なので、必ず図の下に `caption` で「会話はあくまでイメージ」と書く。
- 吹き出しは3つまで。続きは矢印で成果物の箱（枠 `accent`）へつなぐ。
- Slides 形式のマークアップは `slides.md`「会話のイメージ図」。
