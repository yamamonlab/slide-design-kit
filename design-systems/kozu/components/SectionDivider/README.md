# SectionDivider

章扉。左上のパンくず、章番号と題、右の抽象の線画で、デッキを3〜4章に区切る。

- 地は `ground`。パンくずは `rule-mid` の線（160px）と点（14px）＋資料名（`caption`・`ink-3`）。
- 章番号は `accent`・40px・900、題は `divider-title`（64px・900）、その下に「この章で話すこと」を1行（32px 以下）。
- 右の線画は人とAIがつながる抽象の図：中央の円と、外周の点6つ（白抜き＝人、塗り＝AI）を `rule-mid` 3px の線で結び、外側に破線の円。具体物・人物・キャラクターは描かない。章扉のたびに同じ線画を使う。
- 本文スライドには章の表示を出さないので、章扉の題は目次や構成と同じ文言にする。
