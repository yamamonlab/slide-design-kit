# TimeBand

区間の長さを時間に比例させた帯。当日の流れ・タイムテーブル・進め方の時期を見せる（Kiban のパターン「時間軸」の Kozu 版）。

- 帯は高さ 76px、外枠 `rule` 3px・`radius-avatar`、区間の境は `rule` 3px の縦線。区間の中には長さ（「15分」）だけ書く。
- 区間の面：導入・締めは `surface`、主役の区間は `ink` 塗り（文字 `on-ink`）、体験は `tint`、交流は `sunk` 寄りの灰。色だけに頼らず、上の括弧で「導入／体験／交流」と語でまとめる。
- 下に開始時刻（`caption`・`ink-3`・等幅数字）と区間名（26px・700）。5分の区間でも2文字×2行で収まる幅（約 72px）にする。
- 幅は 1分＝本文領域の幅÷全体の分数。計算した幅は合計が 1728px になるよう端数を最後の区間で吸収する。
