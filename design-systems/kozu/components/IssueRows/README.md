# IssueRows（論点の行）

1行に1論点の横長のパネルを重ね、左から 論点（と出どころ）｜原資料の記述 → そこから言えること と横に読ませる。

- 使うとき：読むときの注意、よくある読み違い、判断の根拠のように「事実から何が言えるか」を2〜4つ並べるとき。3列のパネルにすると中身が少なく空く。
- 上に列の見出し（24px・700、`ink-3`）。言えることは白い箱に太字。原資料の記述は細字で、原文に忠実に書く。
- 出どころ（節の名前や日付）を論点の下に必ず書く。
- Slides 形式のマークアップと CSS は `slides.md`「論点の行」。見本：X のおすすめ欄 10枚目。
