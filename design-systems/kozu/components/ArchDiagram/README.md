# ArchDiagram

システムの構成図。部品の箱（ノード）、実行場所の境目（ゾーン）、直角の線と短いラベルで「どこで・何が・何を渡すか」を見せる。順番を見せるなら `PanelFlow`、構成を見せるならこれ。

- ノードの意味は面と枠で表す：処理＝`surface`、置き場＝`sunk`、AI＝`tint`、外部・人＝`rule-mid` の破線枠、未確定＝`sunk` に破線枠＋タグ「予定」、焦点＝枠だけ `accent`（1つまで）。
- ノードの中は タグ（`ink` 塗りの小札：製品名か種類）→ 名前 → 補足1行。
- ゾーンは実行場所・持ち主の境目だけ（2〜3個）。外部のゾーンは破線。
- 線は直角、`rule` 3px、開いた矢じり。交差させない。ラベルは流れる物の名詞（6字まで）。
- 注記は補足（`ink-3`）と、仕組みの要（太字、1つ）。引き出し線は使わない。凡例は図の下に1行。
- ノード8つ・線10本まで。超えたら全体図と詳細図に分ける。
- Slides 形式のマークアップと CSS は `slides.md`「構成図」。決まりの全文は README「構成図（システム・アーキテクチャ）」。
