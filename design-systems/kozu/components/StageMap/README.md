# StageMap（段の地図）

処理の段の流れを上に置き、各段に効く工夫・原則をカードにして、その段の真下に短い縦線で吊るす。全体に効くものは上の括弧に書く。

- 使うとき：設計の考え方・原則・工夫のように、同じ重さの項目が4〜6つ並ぶとき。3×2のカードに並べると、どこに効くかが見えない。
- 段は工程ボックス（AI が担う段は `tint`）と細い矢印。カードは `surface`、`rule` 3px、`radius-node`。見出し 28px・700、本文 24px。
- リード文で言う1つだけ、カードの枠を `accent` に。
- 1つの段に吊るすカードは2枚まで。
- Slides 形式のマークアップと CSS は `slides.md`「段の地図」。見本：おすすめ欄 8枚目。
