**白い紙に、細い数字が1つ。** 余白を主役にして、1枚で1つのことだけを言うスライド体系。数字は細く大きく、図は線と淡い面だけ。写真を使うときは余白の中に1枚だけ置く。1920×1080。

基盤 Kiban v1.1 に従う。基盤と違う点は下の表のとおり。スライドを作る前に、このページと `slides.md` を読む。

## 基盤との違い

| 項目 | 基盤 | 余白 | 理由 |
|---|---|---|---|
| タイトル | 48〜64px の見出し | 見出しを置かない。左上の小さな `tag`（24px）が何の数字かを書き、主役は数字か言い切り | 余白を最大にするため |
| 文字の太さ | 400・700 | 200・300・400 だけ。太字は使わない | 細さで静けさを出す |
| 主要指標 | mono 128px | `huge` 280px・200 | 1枚1数字 |
| 余白 | 左右 96px | 左右 160px、上 120px | 面積の半分以上を空ける |
| 色 | 強調色 1 | 強調色なし。墨と灰と白だけ | 写真が入ったときに色を写真に任せる |
| 角 | 既定は角を立てる | すべて 0 | 線の四角を主役にする |

## 語り口

- 文は短く言い切る（「30年で、約2倍。」）。句点まで書く。
- 1枚に数字は1つ。2つ目の数字は `say` の文の中で言う。
- 言い換え（「7戸に1戸」）や丸め（「約2倍」）は、`note` で「当資料の言い換え」と書く。
- 出典は毎枚、左下の行に。

## 形

- **空きの四角**：線だけの四角（`ink` 2px、面は `ground`）＝空いているもの。**面の帯**（`fill`）＝全体。全体の帯は必ず `ink` の枠で囲む（`fill` は地と 1.2:1 しかない）。
- **比率の帯**：横 1600px の帯を、全体（面）と部分（空きの四角）に分ける。長さは数値に比例させる。
- **推移**：細い縦線と点だけ。強調する2点だけ `ink`、ほかは `line`。数値のラベルも強調する2点だけ。
- **数字を3つ並べる**：上に `ink` の細線、下に `figure` と2〜3行の説明。
- **写真**：余白の中に1枚だけ、縦長か横長で大きく。枠いっぱいに広げず、周りに余白を残す。出典（撮影者・掲載元・利用条件）を写真の下か横に必ず書く。

## 写真の扱い

- 自分で撮った写真か、利用条件を確かめた写真だけを使う（例：官公庁の「政府標準利用規約」で出典を書けば使える写真）。
- 他人の写真を「引用」として使えるのは、本文が主で写真が従、その写真が必要な理由がある、出典を書く、のすべてを満たすときだけ。雰囲気のために載せる使い方は引用にならない。
- 写真が届くまでは `photo` の仮の枠を置き、何の写真が入るかを枠の中に書く。

## 選ばれる条件と得意技

Kiban `routing.md` の問い2で「大きな1文・1つの数字・写真」が主役のとき。型は登壇LT が中心（解説の要所に数枚まぜてもよい）。

- **得意技**：1枚1数字（`BigNumber`）、空きの四角と比率の帯（`EmptyBar`）、余白の中の写真（`PhotoFrame`）。
- **苦手**：数字が多い・関係が複雑な図は密図、構成図は Kozu。

## やらないこと

- 太字、強調色、影、角丸、アイコン。
- 1枚に数字を2つ以上大きく置くこと。
- 写真を枠いっぱい・画面いっぱいに置くこと（余白がなくなる）。
- 24px 未満の文字。

## 出典

- 見た目の方向：余白を生かす日本のミニマルなデザインの考え方を言葉にして置き換えた。特定の作品・ロゴ・写真は使っていない。
- 見本デッキ：[空き家は、900万戸。](../../samples/akiya/)（総務省「令和5年住宅・土地統計調査」ほか）。
